El crossfit es un deporte híbrido — combina levantamiento, gimnasia, cardio y carrera corta. La zapatilla correcta debe equilibrar estabilidad para pesos, flexibilidad para gimnasia y amortiguación para impacto. Una zapatilla de running NO sirve para crossfit.

## Qué hace distinta a una zapatilla de crossfit

- **Plataforma plana y estable** — drop bajo (0-4mm) para levantamientos
- **Talón rígido** — para box jumps y squats con peso
- **Suela durable** — resiste cuerda escalonada y burpees
- **Flexibilidad en antepié** — para movimientos dinámicos
- **Soporte lateral reforzado** — para movimientos multidireccionales

## Por qué NO usar zapatillas de running

**Errores graves al usar running para crossfit:**

1. **Talón blando** → inestabilidad en squats y deadlifts (riesgo de lesión)
2. **Drop alto (10-12mm)** → genera ángulo incorrecto en levantamientos
3. **Plataforma estrecha** → poco soporte lateral para movimientos multidireccionales
4. **Suela suave** → se destruye con burpees y cuerda escalonada

## ¿Mujer u hombre?

La mayoría de las marcas ofrece versiones específicas para mujer:
- **Talón proporcionalmente más estrecho**
- **Antepié más ancho proporcionalmente**
- **Pesos más bajos** — entre 250-290g

## ¿Qué talla pido?

Las zapatillas de entrenamiento se usan más ajustadas que las de correr: el pie no debe moverse dentro en saltos ni en cambios de dirección, pero los dedos tienen que poder abrirse al apoyar. Mide el pie por la tarde, cuando está algo más hinchado, y con el calcetín con el que entrenas. Deja algo de margen en la puntera, aunque menos que en una zapatilla de running. Cada marca talla de forma distinta, así que revisa la guía de tallas de la marca en la ficha de Amazon y compárala con tu medida en centímetros. Si tienes el pie ancho, comprueba si el modelo tiene versión ancha.

## Preguntas frecuentes

**¿Una zapatilla de crossfit sirve para correr?**
Para 1-3 km dentro de un WOD sí. Para entrenamientos de running puro (5K+) no — la falta de amortiguación generará molestias. Para eso, mejor una zapatilla de [entrenamiento diario](/zapatillas-running-entrenamiento-diario/).

**¿Cuánto duran las zapatillas de crossfit?**
6-12 meses con uso regular (3-4 veces por semana). Cuerda escalonada y burpees son los enemigos.

**¿Necesito una zapatilla específica para levantar peso?**
Solo si los levantamientos pesados son el centro de tu entrenamiento. Para crossfit recreativo, una Nike Metcon 9 o una Reebok Nano X4 cubren bien fuerza y cardio; si priorizas el peso, la PUMA Fuse 3.0 da más estabilidad.

**¿Mismas zapatillas para gym tradicional y crossfit?**
Sí, pero las de crossfit están mejor diseñadas para movimientos compuestos. Las de gym puro a veces sacrifican estabilidad por comodidad. Si tu entrenamiento es más de gimnasio, revisa las [mejores zapatillas de gym para hombre](/mejores-zapatillas-gym-hombre/).
